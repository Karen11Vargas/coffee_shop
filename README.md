## Pasos para el uso


**1. Clonar reporsitorio**
**2. Asegurarse de tener instalado el entorno virtual**
**3. Crear el entono virtual**

```bash
  python3 -m venv env
```

**4. Iniciarlo**

```bash
 source env/bin/activate
```

**5.Instalar dependencias**

```bash
 pip3 install -r requeriments.txt
```

**6.Ejecutar Servidor**

```sh
./manage.py runserver
```

**7.Ejcutar Migraciones**

```sh
python manage.py migrate

```

## Bases de datos 🗄️
- Se usa SQLLite, para usar una version gratuita, se recomienda:

```sh
sudo apt install sqlitebrowser

```

- Abrir vista 

```sh
sqlitebrowser
```

## Usuario Admin

Para crear un usuario admin y hacer uso del modulo de administrador, se debe:

 
```sh
./manage.py createsuperuser
```
